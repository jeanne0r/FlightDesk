# Boîtier

Objectif :

- impression 3D sans CNC ;
- écran légèrement incliné ;
- grille du haut-parleur à l'arrière ou sous la base ;
- accès direct au port USB-C ;
- deux ou quatre inserts thermiques ;
- démontage sans colle ;
- aucun bouton mécanique obligatoire.

Les fichiers STEP, STL et Fusion 360 seront ajoutés après mesure de la carte
physique.
