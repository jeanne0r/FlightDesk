## Reddit / Forum

I am building **FlightDesk**, an open-source personal aircraft radar for small
round ESP32-S3 touch screens.

The current prototype runs on a Xiaozhi Ball V2 using ESPHome. A local
FlightDesk server renders the 240x240 radar UI, fetches live aircraft data from
Internet sources, adds an OpenStreetMap-style green watermark, and returns
aircraft popups with route/type/photo details when available.

Repo: https://github.com/jeanne0r/FlightDesk

Interested in feedback from people who have round ESP32 displays, ADS-B
projects, ESPHome experience or ideas for making the UI readable on a tiny
screen.
